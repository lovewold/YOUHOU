# 停推任务执行步骤

## 1. 执行前准备

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 准备本次要上传的 CSV 文件 | 本次任务只需要一个 CSV 文件，所有命中账户共用 |
| 2 | 确认本次要操作的代理商 | 四个代理商分别在各自浏览器中执行 |
| 3 | 确认本次要操作的业务线或账户 | 支持按业务线或指定账户执行 |
| 4 | 确认本次要修改的定向包名称 | 可以指定一个或多个，例如空调停推包、电视停推包 |
| 5 | 打开对应代理商浏览器 | 浏览器需保持巨量引擎登录态 |
| 6 | 进入巨量本地推升级版工作台 | 插件从工作台开始执行更稳定 |

## 2. 配置任务

在油猴面板中填写字段即可，不需要编辑 JSON。

| 字段 | 要填什么 |
| --- | --- |
| 任务名称 | 本次任务名称 |
| 执行模式 | 一般选择「按业务线筛选」 |
| 业务线 | 本次要停推的业务线 |
| 代理商 | 当前浏览器对应的代理商 |
| 定向包名称 | 本次要修改的一个或多个定向包名称，一行一个 |
| 账户备注 | 一行一个账户备注 |
| CSV 文件 | 正式执行前选择本次要上传的 CSV |
| dryRun | 首次试跑勾选，确认无误后取消勾选 |

## 3. 执行顺序

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 在当前代理商浏览器中打开油猴面板 | 面板读取上次保存的表单 |
| 2 | 点击任务预览 | 显示命中账户、定向包列表、CSV 文件 |
| 3 | 核对命中账户 | 确认没有多选或漏选 |
| 4 | dryRun 试跑 | 验证账户定位和任务范围，不提交保存 |
| 5 | 查看 dryRun 日志 | 确认账户、定向包列表、CSV 路径都正确 |
| 6 | 将 `dryRun` 改为 `false` | 准备正式执行 |
| 7 | 再次预览并确认 | 人工确认后开始正式任务 |
| 8 | 插件逐账户执行 | 每个账户依次处理所有指定定向包 |
| 9 | 查看任务日志 | 确认成功、失败和跳过账户 |
| 10 | 处理失败账户 | 根据日志补跑或人工处理 |

## 4. 单账户内执行逻辑

对每个命中账户，插件按以下顺序执行：

1. 在工作台按账户备注搜索账户。
2. 进入账户。
3. 关闭活动弹窗。
4. 进入「工具 > 定向包」。
5. 按面板中填写的第一个定向包名称查找定向包。
6. 修改行政区域并上传本次 CSV。
7. 保存并等待成功提示。
8. 继续处理下一个定向包名称。
9. 当前账户所有定向包处理完成后，返回工作台。
10. 继续下一个账户。

## 5. 注意事项

| 场景 | 处理方式 |
| --- | --- |
| 找不到账户 | 当前账户失败，记录日志，继续下一个账户 |
| 找不到某个定向包 | 当前账户该定向包失败，记录具体名称 |
| 上传失败 | 按配置重试，仍失败则记录日志 |
| 保存后没有成功提示 | 记录保存失败，不继续误判成功 |
| 连续失败过多 | 自动暂停任务，人工检查页面是否变化 |
